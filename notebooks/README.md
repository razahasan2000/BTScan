# Notebooks

This directory contains Jupyter notebooks for exploration and analysis.

## Available Notebooks

| Notebook | Description |
|----------|-------------|
| `01_data_exploration.ipynb` | Dataset exploration and visualization |
| `02_model_training.ipynb` | Model training walkthrough |
| `03_model_evaluation.ipynb` | Model evaluation and metrics |
| `04_ablation_study.ipynb` | Ablation study results |
| `05_xai_analysis.ipynb` | XAI consensus analysis |
| `06_results_visualization.ipynb` | Results visualization |

## Usage

```bash
# Start Jupyter notebook server
jupyter notebook

# Or use JupyterLab
jupyter lab
```

## Dependencies

Install additional dependencies for notebooks:
```bash
pip install jupyter jupyterlab ipywidgets
```

## Note

Notebooks are provided for exploration purposes. For reproducibility, use the scripts in `src/` instead.
